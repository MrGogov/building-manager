# Building Manager

Next.js + Supabase MVP for professional building managers and tenants.

## Run locally

1. Install Node.js 20+.
2. Copy `.env.example` to `.env.local`.
3. Add the Supabase project URL and publishable/anon key.
4. Run `npm install`.
5. Run `npm run dev`.

## Deployment

Import this repository into Vercel and add the same environment variables.

Do not commit service-role keys or other secrets.
