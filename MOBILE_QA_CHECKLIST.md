# Building Manager mobile QA checklist

## iPhone / iOS
- Safari login/logout
- Add to Home Screen and standalone launch
- EN/BG persists
- Tenant and manager invitation links
- Building switcher
- Building Status apartment taps
- Issue actions
- Apartment Overview tabs
- Building Notices create/edit/complete
- Profile photo picker
- Keyboard and modal behavior
- Offline banner/reconnect

## Android
- Chrome install prompt
- Standalone launch
- Back button behavior
- Same manager/tenant flows
- File/photo picker
- Invitation links
- Offline fallback

## Common
- Long names and messages
- Slow network
- Refresh while logged in
- Close/reopen installed app
- Building permission isolation
